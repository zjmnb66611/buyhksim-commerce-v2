# TSK-008：全站语言切换

## 目标

用户在消费者商城选择简体中文、繁体中文或英文后，当前页面及后续访问页面的导航、正文、按钮、表单、提示、商品信息和金额格式同步切换。

## 范围

- 包含：消费者商城全部现有页面、购物车抽屉、移动导航、Toast、ARIA 标签、`html lang` 和页面标题。
- 不包含：用户自行输入的内容、订单号、SKU、运营商品牌名和第三方网络名称。

## 验收场景

- Given 用户位于任意商城页面，When 选择 English，Then 页面可见固定文案与动态反馈均显示英文。
- Given 用户已选择繁体中文，When 跳转商品、购物车、结算、订单、账户或企业采购页，Then 语言选择保持且页面继续显示繁体中文。
- Given 翻译词条暂未配置，When 页面读取该词条，Then 安全回退到简体中文源文案，不显示空白或键名。

## 验证

- `pnpm --filter @buyhksim/i18n test`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- 静态导出构建与线上关键页面冒烟验证。
