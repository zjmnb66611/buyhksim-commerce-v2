# TSK-009 管理后台视觉、交互、性能与安全加固

## 问题清单

1. 深色主题下弹窗、输入框、筛选框和表头存在固定白色背景，形成白字白底。
2. 商品批量导入按钮、表头和其他功能栏使用不同的固定颜色，主题不一致。
3. 静态导出路径带尾部斜杠，侧栏使用严格字符串比较，当前栏目高亮失效。
4. 每个页面重复挂载管理后台外壳，路由切换会重新初始化主题并引发闪屏。
5. 主题在 React effect 运行后才恢复，首次绘制可能出现亮暗主题跳变。
6. 部分 `span` 内嵌套 `p` 的无效 HTML 会触发 React 水合错误。
7. 弹窗没有统一的主题表面、焦点循环、Escape 关闭、遮罩关闭和焦点回收。
8. “下载日报”只有提示，没有生成真实文件。
9. CSV 解析无法正确处理引号和字段内逗号，导出内容存在表格公式注入风险。
10. Excel 批量导入只做扩展名预检，没有逐行解析。
11. 本地存储内容缺少结构和数量校验，异常数据可能导致页面崩溃。
12. 管理后台没有自动测试，无法阻止固定白底、弹窗和路径问题回归。
13. EdgeOne 不识别 `_headers` 文件，线上缺少 CSP、防点击劫持等响应头。
14. 侧栏分组标题和浅色表头对比度略低于 WCAG AA 4.5:1。

## 已完成修复

- 建立浅色/深色语义颜色令牌，统一 `surface`、`field-surface`、`table-head`、`primary-action` 和 `secondary-action`。
- 将管理后台外壳提升到根布局，客户端路由切换时保持侧栏、顶栏和主题实例不变。
- 在 hydration 前执行最小主题初始化脚本，消除首屏主题跳变。
- 规范化尾部斜杠路径，侧栏使用 `aria-current="page"` 表示当前栏目。
- 新建可访问的统一弹窗组件，支持 Escape、遮罩关闭、焦点循环、焦点回收和滚动锁定。
- “下载日报”和工作区导出均生成真实 CSV，并对公式起始字符进行转义。
- CSV 支持引号、转义引号和字段内逗号；Excel 使用按需加载的 ExcelJS 逐行解析。
- 批量导入限制 20MB/10,000 行，校验必要列、重复列、重复 SKU、类型、价格和库存。
- 对商品、内容和工作区本地草稿增加类型、长度和数量校验，损坏数据自动清理。
- 新增加载态、错误边界、404 页面、跳到主要内容链接和 reduced-motion 支持。
- 使用 `edgeone.json` 配置 CSP、HSTS、X-Frame-Options、nosniff、Permissions-Policy、COOP、CORP 和禁止索引。

## 验证结果

- 管理后台单元/组件/主题测试：8/8 通过。
- ESLint、TypeScript、Next.js 静态构建通过；15 个页面完成预渲染。
- npm 生产依赖安全审计：未发现已知漏洞。
- Edge 在线回归：12 条页面路由通过，无页面异常、控制台错误或高严重度无障碍问题。
- 实际侧栏客户端切换：26–41ms，后台外壳保持不变，主题不丢失。
- 390×844 移动端：无页面横向溢出；导航和商品弹窗可操作。
- 线上安全响应头已通过真实 HTTP 响应检查。

## 交付边界

当前公开地址属于生产级沙箱前端：商品、内容和运营记录可由客户在浏览器中自主维护并验证流程，但数据仍保存于浏览器本地。正式交付真实商用环境前，必须接入已有 API、PostgreSQL、RBAC 登录、服务端审计和私有管理域名；静态预览链接不能替代正式后台鉴权。
