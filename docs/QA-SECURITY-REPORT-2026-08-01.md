## 已修复的高风险问题

- 支付/订单越权、分销用户 ID 冒用、提现重复占额、退款并发超额。
- 重复/并发/晚到支付回调，支付成功后库存仍处于锁定状态，超时订单库存不释放。
- 前后台刷新令牌互相覆盖、并发刷新导致会话误退出、已撤销会话仍可继续访问。
- 商品和批量导入仅写浏览器、本机地址/订单/询价假保存、后台虚假经营/健康数据。
- 后台新增商品在前台收藏、购物车、结算或静态商品详情中丢失。
- 无依据的销量、评价、覆盖数量、客服时效、退款和交付宣传。
- 生产 CSP 无法连接外部 API、API CSP/HSTS 缺失、生产密钥和 PII 加密密钥未强制检查。
- 静态托管 CSP 阻断 HTTPS API/OSS 资源，以及后台退出只清本机访问令牌但未撤销服务端刷新会话。
