# BUYHKSIM V2 功能、性能与安全复测

日期：2026-08-01

## 已通过

- 消费者商店 `3100`、商家后台 `3101`、API `4000` 均处于监听状态并返回 HTTP 200。
- 首页、账户、订单、结算、商品详情、后台首页、商品、内容、订单共 9 个核心路由连续请求全部成功。
- 5 次本机热请求平均响应：13.3ms 至 39.4ms；单路由最大值 71.7ms。
- 后台商品导入、退款、分销、AI 后台文案接口在无令牌时均返回 401。
- 支付回调使用伪造签名时返回 401。
- 前台与后台均返回 CSP、X-Frame-Options=DENY、X-Content-Type-Options=nosniff；API 由 Helmet 提供安全头。
- 生产依赖审计：0 个已知漏洞。
- Lint：通过。
- TypeScript：通过。
- 单元测试：12/12 通过。
- 生产构建：通过。

## 本轮修复摘要

- 修复本地预览端口与 API 构建输出路径，增加一键启动/停止脚本。
- 补齐 NestJS 运行依赖，API 健康检查恢复。
- 增加 JWT 鉴权、权限校验、严格 CORS、限流、生产密钥长度检查、错误脱敏和原始支付回调验签。
- 加固 CSV/XLSX 上传：文件大小、数量、扩展名、魔数、非法二进制、列名、重复列和最大行数。
- 修复后台空操作按钮，新增真实可编辑运营工作区、商品批量操作和店铺内容维护。
- 优化图片传输体积，并移除结算流程中不必要的 700ms 人工等待。
- 增加全局文本防溢出、图标防收缩、移动头部断点与后台移动导航。

## 待用户授权的最后门禁

应用内浏览器连接组件不可用。根据 Product Design 规则，使用独立 Playwright 前需用户明确授权；因此多尺寸截图对比、真实点击矩阵和无障碍浏览器扫描暂未执行，不能把视觉 QA 标记为最终通过。
