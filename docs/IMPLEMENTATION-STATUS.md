# BUYHKSIM V2 实施状态

更新日期：2026-08-03

## 本轮已落地

- PostgreSQL 权威商品目录、单商品新增/编辑/上下架、SKU、价格和库存维护。
- CSV/Excel 服务端校验、逐行错误、持久化导入任务、幂等提交和审计日志。
- 注册登录、Argon2id、短期访问令牌、前后台独立 HttpOnly 刷新会话、会话轮换/撤销、RBAC 和商户隔离。
- 地址加密存储，登录后的收藏、购物车、地址和订单改为服务端同步；删除伪造订单、评价、销量和经营指标。
- 后台新上架商品可由前台目录、收藏、购物车和结算读取；购物车保存商品快照，静态部署也通过通用商品详情入口访问新增商品。
- 服务端权威结算、用户归属校验、价格快照、积分/优惠券占用、库存跨仓锁定和订单幂等。
- 支付创建防重复、订单归属/超时校验、回调验签与字段核对、并发回调串行化、晚到回调异常事件。
- 支付成功后库存从 `LOCKED` 原子转为 `SOLD`；订单超时自动归还库存、积分和优惠券。
- 退款按商户隔离，并将待处理退款计入可退余额，防止并发超退。
- 分销关系防自邀/循环，统计只允许查看本人；提现按本人和幂等键隔离，并扣除待审核提现占额。
- 企业询价加密入库、频率限制和真实受理编号。
- CMS 简体中文/繁体中文/英文草稿与发布、审计，以及消费者首页读取已发布内容。
- 后台权限登录、真实经营概览，以及订单、库存、售后、用户、分销、财务、审计和风控只读运营视图。
- API 严格 CORS、Helmet/CSP、HSTS 生产配置、请求大小限制、全局限流、生产密钥门禁、PII AES-256-GCM。
- 静态托管 CSP 允许连接 HTTPS API 与读取 HTTPS 商品资源，修复上线后请求被浏览器安全策略拦截的问题。
- 前后台主题和前台三语言覆盖测试；移除未经数据支持的销量、好评率、覆盖数量、客服时效和无条件退款宣传。

## 仍不能标记为正式生产完成

- 正式微信支付、支付宝、银联商户凭证未提供，当前只允许沙箱契约，不能收取真实资金。
- 短信/邮件、eSIM 供应商、物流、OSS/KMS 凭证未提供，安全领取、自动发货、物流同步和通知链路尚不能完成生产联调。
- 当前环境没有已配置的 PostgreSQL/Redis 测试实例，本轮未执行真实迁移、并发数据库集成、恢复演练和故障注入。
- 运营主体、隐私政策、销售条款、退款/物流规则、ICP备案与域名资料未提供，不能代替客户生成具有法律效力的最终文本。
- 未启动本地服务，未进行浏览器端多尺寸视觉回归和端到端点击测试；这是正式发布前的必过门禁。
- 营销活动、会员规则、售后审批、财务审核、物流操作等后台目前只有真实只读视图，写入状态机仍需按业务规则补齐。

以上项目未满足前，不得对外宣称“正式生产可收款”或“全部功能已验收”。
