# 实施状态

更新日期：2026-08-01

## 已实现

- 独立 pnpm Monorepo、前台、商家后台、NestJS API、共享契约、设计系统、i18n 与 Drizzle 数据层。
- 所选“可信交易型商城”首页、商品搜索/筛选、详情、收藏、持久化购物车、结算、订单、企业询价、三主题和三语言设置入口。
- 商家经营概览、商品表格、单个建品、CSV/Excel 导入、逐行错误反馈、模板下载、批量上架/下架/改价/库存入口。
- PostgreSQL 40 张核心表、两份结构迁移和全新沙箱演示数据。
- 服务端权威价格、短期预览签名、库存条件锁定、订单/商品/优惠快照、持久幂等、事务 Outbox。
- 微信、支付宝、银联沙箱适配契约；回调验签并核对商户、订单、金额、币种和渠道流水；重复/晚到回调分支；部分退款边界。
- Argon2id 登录、短访问令牌、HttpOnly 刷新会话、RBAC 与商户隔离守卫。
- 多级推广关系记录、默认一级佣金、防自邀/防循环、提现财务审核契约。
- OpenAI Agents SDK 受控只读商品工具、故障关闭回退、PII 基础脱敏、人工确认和工具拒绝清单。
- CI、密钥扫描、迁移验证、国内 Docker 镜像、PostgreSQL/Redis 本地编排与运维基线。
- 后台所有运营模块已由静态提示升级为可搜索、新建、编辑、更新状态与导出的工作区；商品管理支持持久草稿、单品编辑、批量改价、批量调库存和 CSV 实际预校验。
- 新增店铺内容管理，支持简体中文、繁体中文、英文分别编辑、预览、保存草稿与发布；新增后台移动导航和跟随系统/浅色/深色主题。
- 用户中心补齐正式 API 登录、沙箱体验、地址簿、会员、积分、优惠券和会话管理；订单页补齐物流详情与 eSIM 二次验证流程；结算优惠券和企业询价可实际提交并生成编号。
- API 新增全局限流、生产密钥门禁、严格 CORS、Helmet、JWT 敏感接口鉴权、RBAC、上传魔数与行数校验、支付原始请求体验签和 5xx 错误脱敏。
- 修复本地启动链路，消费者商店、商家后台与 API 现分别监听 3100、3101、4000；提供 `scripts/start-local.ps1` 与 `scripts/stop-local.ps1`。
- 商品与首页图片转换为 WebP，单图由约 2–2.7MB 降至约 0.1–0.27MB；九个核心页面本地热响应平均 13–40ms。
- 生产依赖审计已从 9 个已知漏洞降为 0 个；Lint、TypeScript、12 项单元测试与生产构建全部通过。
